- C++11 or later

## 🚀 Compile and Run

### Compile a single practical

```bash
g++ Practical01.cpp -o Practical01
```

### Run on Windows PowerShell

```powershell
.\Practical01.exe
```

### Compile Practical 11 — List Container

```powershell
g++ "Practical11.cpp\List Container.cpp" -o ListContainer.exe
.\ListContainer.exe
```

### Compile Practical 11 — Vector Container

```powershell
g++ "Practical11.cpp\Vector Container.cpp" -o VectorContainer.exe
.\VectorContainer.exe
```

Replace `Practical01.cpp` with the desired practical filename when compiling another program.

- Apply object-oriented programming principles in C++.

- Implement inheritance and polymorphism.
- Manage dynamic memory using pointers and references.
- Handle runtime errors using exception handling.
- Use templates to write generic and reusable code.
- Work with STL containers and utilities.
- Understand type conversion and casting operators.
